# HoloRescue Cube

An AI-powered disaster response cube that helps search-and-rescue teams locate survivors, detect hazards, and map dangerous environments in real time.

## Overview

HoloRescue Cube is a portable, intelligent search-and-rescue device designed for use during earthquakes, building collapses, mine accidents, floods, and other disasters. It combines AI, computer vision, thermal imaging, gas detection, and depth sensing to improve rescue operations while reducing risk to first responders.

The system is built around a Raspberry Pi 5 and ESP32, allowing high-performance AI processing alongside reliable sensor management. It streams live data to a dashboard where rescue teams can monitor conditions and make informed decisions before entering hazardous areas.

---

## Features

-  AI-powered survivor detection
-  HD live camera streaming
-  Thermal imaging for locating survivors
-  Toxic gas detection (CO, smoke, LPG, air quality)
-  Time-of-Flight obstacle detection
-  Real-time environment mapping
-  Two-way communication
-  Live monitoring dashboard
-  Portable battery-powered operation
-  Wireless communication

## Hardware

- Raspberry Pi 5 (8 GB)
- ESP32 DevKit
- Raspberry Pi Camera Module 3 NoIR
- MLX90640 Thermal Camera
- VL53L1X ToF Sensor
- MQ-2 Gas Sensor
- MQ-7 CO Sensor
- MQ-135 Air Quality Sensor
- Microphone
- Speaker
- Battery Pack
- LEDs and Buzzer
